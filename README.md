# TeamSync Pro - 團隊協作系統

## 📋 專題名稱

**多功能團隊協作平台：任務管理 + 即時聊天 + 智能打卡**

---

## 🎯 專案簡介

TeamSync Pro 是一個全功能的團隊協作平台，旨在解決遠端與實體團隊的溝通斷層。透過整合任務追蹤、即時通訊與考勤系統，讓團隊成員能在同一個介面上完成所有協作。

* **核心架構**：FastAPI (Python 3.10+) & React 18 (TypeScript)
* **技術亮點**：
* **即時同步**：全站 WebSocket 連線，聊天訊息與任務狀態秒級同步。
* **直覺互動**：支援看板拖拽、**日曆拖拽排程**、聊天訊息轉任務等多種互動方式。
* **精準考勤**：自動處理 **UTC+8 台灣時區**，精確計算工時。
* **個人化體驗**：支援**自定義頭像上傳**與深淺色模式切換。

## 🚀 快速啟動 (Installation)

### 1. 後端 (Backend)

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

```

### 2. 前端 (Frontend)

```bash
cd teamsync-pro-團隊同步1
npm install
npm run dev

```

## ✨ 核心功能詳解

### 1️⃣ 儀表板 (Dashboard)

儀表板是個人的工作數據中心，提供即時狀態與快速設定。

* **考勤系統**：整合台灣時區的即時時鐘，一鍵完成「上班打卡」與「下班簽退」。
* **個人化頭像**：**支援自定義照片上傳**。上傳後，頭像將即時同步於儀表板、團隊聊天室及任務指派清單中，強化團隊辨識度。
* **自動工時計算**：根據簽到退時間，系統自動計算並顯示當日工作時數。
* **任務概覽卡片**：即時統計「待處理」與「逾期」任務數量，點擊可直接開啟詳細列表彈窗。

### 2️⃣ 個人任務管理 (Personal Tasks)

#### 🎨 三種視圖模式

* **📋 列表視圖**：按「待處理、進行中、已完成」自動分組，支援收合子任務。
* **📊 看板視圖**：透過直覺的拖拽操作（Drag & Drop）變更任務狀態。
* **📅 日曆視圖**：
* **任務呈現**：所有任務依截止日期呈現在月曆介面。
* **智能排程**：**支援直接在日曆上「拖動」任務卡片至不同日期，系統會自動更新任務的截止時間並同步。**



#### 🛠️ 高階操作

* **子任務管理**：支援多層級清單，並可追蹤完成進度。
* **訊息轉任務**：可將聊天室訊息直接拖放到任務中，快速轉換為子任務。
* **升級機制**：一鍵將個人私有任務「升級」並分派至所屬團隊工作區。

### 3️⃣ 團隊工作區 (Team Workspace)

#### 💬 團隊大廳

* **即時聊天室**：基於 WebSocket 的多人即時溝通。
* **在線狀態**：成員頭像旁附有狀態燈（🟢 工作中 / ⚪ 離線），資訊根據打卡狀態自動切換。
* **貢獻榜 (Stats)**：視覺化橫條圖顯示每位成員的任務完成貢獻度。
* **活動日誌**：詳盡記錄團隊內所有的任務異動與操作者紀錄。

#### 📋 團隊任務協作

* **專屬任務聊天室**：每個任務擁有獨立的討論頻道，僅指派成員可見。
* **權限保護**：僅限被指派者可操作任務狀態，確保團隊分工明確。
